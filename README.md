# Medicine Recommendation System

## Overview

The Medicine Recommendation System is a Machine Learning-based healthcare application that predicts diseases based on user symptoms and provides personalized recommendations, including medications, precautions, diet plans, workout suggestions, and disease descriptions.

The system is designed to assist users in understanding possible health conditions and obtaining useful healthcare guidance through an interactive web interface built with Flask.

---

## Features

* Disease prediction based on user symptoms
* Medicine recommendations for predicted diseases
* Precaution suggestions
* Diet recommendations
* Workout recommendations
* Detailed disease descriptions
* User-friendly web interface
* Machine Learning-powered prediction model
* Fast and accurate disease diagnosis support

## How It Works

1. User enters symptoms through the web interface.
2. Symptoms are converted into an input vector.
3. The trained Machine Learning model predicts the most likely disease.
4. The system retrieves:

   * Disease Description
   * Recommended Medications
   * Precautions
   * Diet Plans
   * Workout Suggestions
5. Results are displayed to the user.

## Installation

### Clone the Repository

```bash
git clone https://github.com/Preetykumari24/Medicine_Recommendation_System.git
```

### Navigate to Project Directory

```bash
cd Medicine_Recommendation_System
```

### Create Virtual Environment

```bash
python -m venv .venv
```

### Activate Virtual Environment

Windows:

```bash
.venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python main.py
```
